# Финальная оценка обхода стены: план до открытия Test

Оценка остаётся закрытой до завершения и фиксации всех четырёх учеников. Исполняемый пример `examples/evaluate_wall_navigation_students.py` по умолчанию только показывает план. Авторитетный состав моделей задаёт `final_cohort_registration.json`: каталог каждой модели указан явно, вместе с хешами исходной регистрации, численного дополнения, решателя и ноутбука. Старые попытки E0 не участвуют в выборе итоговых моделей.

На новых сценах сравниваются исходная модель с NFE **1, 2, 4, 8, 16, 32, 64** и ученики **M0/E0 с NFE4/2**. Условия — восемь непрерывных координат A/B/стены. Идентификатор верхнего или нижнего маршрута не передаётся модели. Зарегистрированный Test: 32 сцены × 128 путей, `seed=20061`, `split='test'`; шум `seed=614001`. Одни и те же 128 начальных состояний внутренних 30 точек повторяются для каждой сцены и используются всеми моделями. Первый вызов фабрики Test происходит после проверки всех завершённых manifests, фактических хешей checkpoint EMA и экспортированных весов, а также совпадения всех 1000 сохранённых scene/interval/data/noise trace между M0/E0 при каждом NFE.

Главная оценка — доля успешных маршрутов с точной проверкой **каждого отрезка** относительно стены с запасом 0,035 и границ сцены. Обе моды считаются только среди успешных однозначных маршрутов; основной знаменатель покрытия — все 32 запрошенные сцены. Отдельно сохраняются длины всех и успешных путей, число коллизий, баланс мод и необработанные результаты каждого пути. A/B восстанавливаются точно на каждом шаге конструкцией модели; точность концов не считается выученным достижением.

Расстояние до реального распределения оценивается 128 фиксированными проекциями SWD в исходном 60-мерном пространстве внутренних координат, без подбора на Test. Главное значение усредняется **по отдельным условиям**; общий SWD по смешанным сценам сохраняется как дополнительная характеристика. Попарный MSE к **Teacher32** и ошибки в общих фактических узлах FM описывают сходство с родителем; геометрическую истинность оценивает только проверка стены. Для каждого ученика также сравнивается исходная модель с тем же NFE.

Это исследовательский прогон с одним seed обучения 161. Всего 4096 сгенерированных путей не заменяют независимые повторения обучения; доверительные интервалы по seed и подтверждающие универсальные выводы не строятся. Численное дополнение решателя сохраняет цель, epsilon и допуск 1e−10 в float64 и отдельно документируется; оба E0 повторяются по одному правилу.

Показывается заранее выбранная сцена 0 и первые 32 шума; для физического воспроизведения берутся первые 4 пути. Неуспешные пути не отфильтровываются и не исправляются. Анимация FM меняет целое состояние маршрута по фактическим узлам Euler; отдельная физическая анимация проходит по сохранённым пространственным waypoint’ам, с красным A и фиолетовым B. Полные истории сохраняются в игнорируемом кэше. Публичные конечные пути и preview копируются в отдельные компактные хранилища, чтобы сериализация среза не включала полную историю.
